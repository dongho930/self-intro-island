# 섬마을 자기소개

작은 섬마을을 걸어 다니며 나를 알아가는 2D 픽셀아트 게임형 자기소개 사이트입니다.
클라우드 데이터베이스 수업의 자기소개 웹앱 과제로 만들고 있습니다.

- 섬의 여섯 장소(집, 도서관, 작업실, 등대, 평상, 우체통)를 둘러보면 스탬프가 찍힙니다.
- 게임 없이 보고 싶은 사람은 **한눈에 보기** 버튼으로 전체 내용을 바로 볼 수 있습니다.
- 광장의 **마을 게시판**은 방명록입니다.

## 내 내용으로 바꾸기

`js/content.js` 파일 하나만 고치면 됩니다. `[대괄호]` 부분을 본인 내용으로 바꾸고 저장하세요.
이름, 소개, 기술 숙련도(1~5), 프로젝트, 걸어온 길, 취미, 연락처, 집주인이 하는 말이 모두 이 파일에 있습니다.

## 내 컴퓨터에서 실행하기

`index.html`을 더블클릭해도 열리지만, 실제 배포 환경과 같게 보려면 간단한 서버로 여는 것이 좋습니다.

```bash
python -m http.server 8000
```

그다음 브라우저에서 http://localhost:8000 을 엽니다.

## 조작 방법

| 기기 | 이동 | 살펴보기 |
|---|---|---|
| PC | 방향키 또는 WASD, 또는 가고 싶은 곳 클릭 | 장소 앞에서 Space, 또는 건물 클릭 |
| 휴대폰 | 가고 싶은 곳 터치 | 건물이나 화면 가장자리의 장소 표지 터치 |

## 파일 구조

```
index.html        화면 뼈대 (시작 화면, 장소 창, 한눈에 보기)
css/style.css     스타일
js/content.js     소개 내용 (여기만 고치면 됨)
js/config.js      방명록 연결 설정 (AppSync 주소, API 키)
js/art.js         픽셀 아트 (캐릭터, 건물, 나무, 아이콘을 코드로 그림)
js/world.js       섬 지도, 길, 장소 위치, 길 찾기
js/guestbook.js   방명록 저장 (미리보기 모드 / AppSync 모드)
js/ui.js          시작 화면, 스탬프, 대화창, 장소 창, 방명록 화면
js/game.js        게임 진행 (이동, 카메라, 그리기)
```

이미지 파일 없이 모든 그림을 코드로 그리기 때문에, S3에는 위 파일만 올리면 됩니다.
글꼴은 CDN에서 불러옵니다. (갈무리: jsDelivr, 고운돋움: Google Fonts)

## 방명록

지금은 **미리보기 모드**입니다. 방명록이 글을 쓴 사람의 브라우저(localStorage)에만 저장되고, 다른 방문자에게는 보이지 않습니다.
AppSync API를 만든 뒤 `js/config.js`에 GraphQL 주소와 API 키를 넣으면 모든 방문자가 같은 방명록을 보게 됩니다.
코드가 기대하는 GraphQL 작업 이름은 기획서와 같은 `listMessages`(조회)와 `createMessage`(작성)입니다.
AppSync 연결 부분은 아직 실제 API로 시험해 보지 않았습니다.

## S3에 올릴 파일

`index.html`, `css/`, `js/` 세 가지입니다. 기획서(.docx)와 `README.md`, `.claude/` 폴더는 올리지 않습니다.
